NAVYA'S BIRTHDAY WEBSITE — FREE SETUP
======================================

FASTEST WAY (laptop/desktop)
1. Extract the ZIP file into a folder.
2. Open the folder and double-click index.html.
3. The website opens in Chrome, Edge, Firefox, or Safari.
4. Tap/click “Play our little tune” to start the original gentle melody.
   Browsers block sound from autoplaying until a person interacts, so this is intentional.

PHONE
- Extract the ZIP using your phone's Files app.
- Some phones don't allow local HTML pages to run all features properly from the file manager.
  If that happens, use a laptop, or publish it free with GitHub Pages (steps below).

OPTIONAL: FREE ONLINE LINK WITH GITHUB PAGES
1. Sign in or create a free account at https://github.com/
2. Create a new PUBLIC repository, for example navya-birthday.
3. Upload index.html and the entire assets folder (keep the folder name assets).
4. Open repository Settings → Pages.
5. Under Build and deployment, choose “Deploy from a branch”, select “main” and “/(root)”, then Save.
6. Wait for GitHub Pages to publish and open the URL shown there. Send that link to Navya.
   This makes the site public to anyone who has the link; don't upload private photos if that concerns you.
   GitHub may change its interface; no paid plan is required for a public Pages site.

ADD MORE PHOTOS OR VIDEOS
- Use the “Add more of our memories” and “Our video corner” upload controls on the page.
- Selected files preview only in that open browser tab. They are not uploaded anywhere and are not saved
  into the ZIP automatically. To make pictures permanently part of the website, place them in assets
  and edit index.html to add another <figure> card, or upload them as part of the GitHub repository.
- If you want Navya to see your added pictures on the online link, add those files to the repository;
  browser uploads are local previews only.

MUSIC / COST
- The tune is generated in the browser with Web Audio. No music file, paid API, or subscription is used.
- The site has no analytics, no paid embeds, and no external asset dependencies.
- It uses the three photos you supplied.
- The “No” button playfully dodges within its area. This is a joke interaction; the site remains usable.
